# Filtreco.RU — шаблон сайта

Лендинг для компании, занимающейся **монтажом и продажей систем водоподготовки**.
Статический сайт на чистом HTML / CSS / JavaScript — без сборщиков и зависимостей.

## Структура

```
/
├── index.html      — главная страница (одностраничный лендинг)
├── css/
│   └── style.css   — стили, адаптивная вёрстка (брейкпоинты 1024px и 760px)
└── js/
    └── main.js     — мобильное меню, маска телефона, валидация формы, анимации
```

## Секции страницы

1. **Шапка** — логотип, навигация, телефон, кнопка «Заказать звонок», бургер-меню
2. **Hero** — заголовок, УТП, CTA-кнопки, SVG-иллюстрация системы фильтрации, статистика
3. **Услуги** — анализ воды, проектирование, монтаж, сервис
4. **Каталог оборудования** — 6 карточек товаров с ценами («от …») и тегами
5. **Как мы работаем** — 6 этапов от заявки до сервиса
6. **Преимущества** — 6 блоков (гарантия, склад, инженеры, юрлица, цены, сроки)
7. **Форма заявки** — имя, телефон (с маской), задача; тёмная секция с градиентом
8. **FAQ** — аккордеон на `<details>`
9. **Подвал** — контакты, навигация, соцсети, копирайт

## Запуск

Просто откройте `index.html` в браузере, либо запустите локальный сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Доработка перед публикацией

- Замените телефон `8 800 123-45-67`, e-mail и адрес на реальные.
- Подключите отправку формы к бэкенду в `js/main.js` (помечено комментарием).
- Замените SVG-заглушки и эмодзи на реальные фото объектов и оборудования.
- Обновите цифры (год основания, количество проектов, цены) на фактические.
- Добавьте страницу `/privacy` и ссылку на политику персональных данных.

Цветовая схема задаётся переменными в начале `css/style.css` (`--c-primary`, `--c-accent` и др.).
